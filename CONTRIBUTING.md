# Contributing

Thanks for helping improve HA Local Memory Tools.

## Before opening an issue

- Search existing issues first.
- Include the Home Assistant version.
- Describe expected and actual behavior.
- Remove access tokens and private memory text.

## Pull requests

1. Keep changes focused.
2. Add or update tests for pure-Python logic.
3. Run `python -m compileall custom_components`.
4. Run `pytest`.
5. Update the changelog for user-visible changes.

Small, reviewable pull requests are preferred.
